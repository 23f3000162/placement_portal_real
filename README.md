# Placement Portal

A full-stack Placement Portal developed using **Flask** for the backend and **Vue.js** for the frontend. This application helps students, companies, and administrators manage placement activities through a centralized platform.

---

## 🚀 Features

### 👨‍🎓 Student
- Student Registration & Login
- View Placement Drives
- Apply for Jobs
- Track Application Status
- Dashboard

### 🏢 Company
- Company Registration & Login
- Create Placement Drives
- View Applicants
- Manage Recruitment Process

### 👨‍💼 Admin
- Manage Students
- Manage Companies
- Manage Placement Drives
- View Applications
- Generate Reports
- Dashboard Analytics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/23f3000162/placement_portal_real.git
```

### Backend Setup

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
